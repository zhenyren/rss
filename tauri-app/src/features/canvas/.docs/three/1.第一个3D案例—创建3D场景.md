# 第一个3D案例—创建3D场景

## 三维场景Scene

```js
// 创建3D场景对象Scene
const scene = new THREE.Scene();
```

## 物体形状：几何体Geometry

```js
// 创建几何体对象Geometry
const geometry = new THREE.BoxGeometry(100, 100, 100);
```
- 更多集合体
  - 球体 （SphereGeometry）
  - 圆柱体 （CylinderGeometry）
  - 圆锥体 （ConeGeometry）
  - 圆盘体 （RingGeometry）
  - 圆柱体 （CylinderGeometry）
  - 立方体 （BoxGeometry）
  - 多边形 （PolygonGeometry）
  - 网格体 （GridGeometry）



## 物体外观：材质Material

```js
// 创建材质对象Material
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
```

## 物体：网格模型Mesh

```js
// 创建网格模型对象Mesh
const mesh = new THREE.Mesh(geometry, material);
```

## 模型位置.position
```js
// 设置模型位置
mesh.position.set(0, 10, 0);
```

## .add()方法

```js
// 将网格模型添加到场景中
scene.add(mesh);
```
